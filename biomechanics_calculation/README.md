# Biomechanics calculation

[`MDD_BIOMECHANICS_CALC.pdf`](MDD_BIOMECHANICS_CALC.pdf): the hand-written working for a single finger:
- tendon force needed to open the finger (average and maximum);
- the cable path over the MCP / PIP / DIP joints;
- spool radius and the torque the motor needs;
- whether the MG996R is strong enough (with a safety factor).
